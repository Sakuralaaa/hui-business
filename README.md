# 汇商跨境经营工作台

云端 Docker 部署的综合经营应用，覆盖阿里国际站 B2B 与零售台账。Accio Work 是可选采集端，原始文件通过同一接收链路进入可追溯的数据与分析系统。

## 使用

按照 [部署说明](docs/deployment.md) 配置服务器的 `.env`，拉取 GitHub Actions 生成的 API / Web 镜像，运行 Docker Compose；初始化管理员后登录。切换到两个演示企业查看模拟数据，真实企业从创建店铺开始。

首版操作顺序：创建采集任务 → 签发 60 分钟上传凭据 → 网页或 Accio 上传 → 查看字段映射和差异 → 人工确认 → 更新经营指标 → 查看证据与行动草稿。

## 当前实现

- React / Ant Design 中文页面、企业切换、店铺范围、管理员邀请、角色与审计。
- 商品、供应商、客户、询盘、报价、样品、订单及明细、采购、库存、收付款、费用、内容、知识及待办。
- 网页上传及 Python 标准库外部上传；凭据范围、期限、撤销，原件封存和 SHA-256。
- CSV、单工作表 XLSX、JSON / JSONL、受限 ZIP；字段映射、行级错误、预览、重复与版本冲突、幂等确认。
- 程序计算多币种分别列示的订单净额、贡献利润、资金流和广告指标；缺少数据时标示不可计算。
- 已确认快照分析、模型接口、加密密钥、月预算预留、费用估算与调用记录；模型建议成为待确认草稿。
- Nono 文案检查 / 竞品文本比较 / 安全导出改造，TradeMind 内容应用 / 版本检查 / 撤销移植，14 个有来源的模板。
- 商品原图保存、尺寸 / 边缘白色比例检查、提示词导出。
- pg-boss 后台任务、数据库行级隔离、磁盘 / S3 存储、备份与恢复指引。

## 需要实际环境验证的部分

Accio 的原始明细导出、朋友账号的接口权限、真实数据字段及完整性，均未因本项目编写而自动验证。官方平台 API 不进行假连接；商品、消息等对外动作先人工执行并记录结果。

目前图片生成支持模板与适配接口，尚未调用实际图片供应商。定时平台采集、平台刊登读回、公众注册 / 收费、pgvector，以及完整结算对账规则留在后续里程碑。首版台账允许记录分批收货、部分履约与退款；特定平台流程需根据样本继续配置。

性能目标、真实 AI 质量、备份恢复演练需按 [验收清单](docs/acceptance.md) 在云端测量。通过 CI 不等于朋友店铺已经接通或效果优于其他工具。

## 仓库结构

| 路径 | 用途 |
|---|---|
| apps/web | 中文工作台 |

| bridge/accio-bridge | 原创 Skill 与上传程序 |
